# E-commerce Sales Analysis Using Python

## Project Overview

This project analyzes e-commerce sales data using Python to understand sales trends, product performance, customer purchasing behavior, and business profitability. It focuses on data cleaning, exploratory data analysis (EDA), and data visualization to generate meaningful business insights and support data-driven decision-making.

## Objectives

- Clean and prepare e-commerce sales data.
- Identify missing values, invalid entries, and duplicate records.
- Analyze total sales and monthly sales trends.
- Identify top-performing products and product categories.
- Evaluate total profit and category-wise profitability.
- Identify top customers based on purchase value.
- Analyze payment methods, order statuses, and regional sales performance.
- Present findings through charts and visualizations.
- Export summary reports for further analysis.

## Project Workflow

1. Load and inspect the e-commerce dataset.
2. Examine columns, data types, missing values, and duplicate records.
3. Clean and prepare the data for analysis.
4. Validate dates, quantities, discounts, and relevant numeric columns.
5. Perform exploratory data analysis (EDA).
6. Analyze sales, profit, products, customers, and categories.
7. Explore monthly trends, payment methods, order statuses, and regional performance.
8. Create charts and visualizations to communicate the results.
9. Export summary reports for further analysis.
10. Document the key findings and conclusions.

## How to Run the Project

1. Clone or download this repository.
2. Install Python and Jupyter Notebook, if not already installed.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Keep the original CSV dataset in the location expected by the notebook.
5. Open the notebook in Jupyter Notebook.
6. Run the notebook cells in order.
7. Review the generated charts, findings, and exported reports.
